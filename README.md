# Dockerized Web Application with Jenkins CI/CD

## Project Overview

This project demonstrates containerization and automated deployment of a web application using Docker and Jenkins CI/CD.

## Project Highlights

- Dockerized a web application by creating a Docker image and running the application inside a Docker container.
- Configured Docker port mapping to expose the application and verified it through a web browser.
- Integrated Docker with Jenkins to automate the Docker image build and container deployment process through a CI/CD pipeline.
- Used Linux, Docker, Jenkins, Git, and GitHub to build, deploy, and manage the project.
